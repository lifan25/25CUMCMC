# Q2 模型与算法

## 1. 采用模型与理由

| 组件 | 采用 | 理由 |
|---|---|---|
| 达标时间模型（主） | 区间删失 AFT（对数正态主选，Weibull 对照按 AIC 选分布） | 直接刻画 F(t\|BMI)；似然天然容纳左/区间/右删失；参数少、可解释、可外推边界清楚 |
| 当次达标概率模型（对照） | 按孕妇聚类的边际 logistic：logit P(y_hit=1\|t,B0) | 不依赖持续达标假设，直接估计 p(t\|BMI)；用于核验 F≈p 及反转影响 |
| 分组优化 | 有序 BMI 分段 + 动态规划 | 组必须是有序连续区间才可执行；DP 在给定网格与目标下给出全局最优分段 |
| 误差传播 | Q1 边际浓度模型 + 独立测量误差 ŝ² | 误差来源可追溯（Q1 正式估计），阈值翻转概率有解析表达 |

备选的重复测量概率模型（P0 提到的生存拟合差时的替代）已由当次 logistic 覆盖；不额外实现非参数区间删失（Turnbull），267 人单协变量下参数 AFT 足够，且校准检验会暴露分布误设。

## 2. 达标时间与删失构造

对每名孕妇 i，事件序列 (t_ij, h_ij)，h_ij=1{Y_ij≥0.04}（采血级，来自 Q1 视图）：

- 首个事件即达标：左删失 `T ∈ (0, t_i1]`；
- 首次由未达标转为达标：区间删失 `T ∈ (t_i,j−1, t_i,j]`；
- 末次事件仍未达标：右删失 `T ∈ (t_i,last, ∞)`；
- 达标后反转（后续 h=0）：不修改首次事件区间（F 的构造基于潜在持续达标假设），单独计数并用当次概率模型核验假设影响。

输出删失视图 `q2_censoring.csv`：pid、类型、左/右端点（周）、事件数、是否反转。

## 3. 达标时间模型（主）

对数正态 AFT（F 为首次跨越累计概率，与当次检测成功概率 p 目标不同、全程区分）：

```
log T_i = α0 + α1·B0_i + σ·ε_i，ε ~ N(0,1)
F(t|B0) = Φ((log t − α0 − α1·B0)/σ)
```

区间删失似然：左删失贡献 F(t_R)，区间删失贡献 F(t_R)−F(t_L)，右删失贡献 1−F(t_R)。
scipy 直接数值极大化（L-BFGS-B），α1 的区间由 Hessian 数值二阶导给出；Weibull AFT 同框架对照，按 AIC 选分布。

锚点方向先验：α1>0（BMI 越高达标越晚）。

## 4. 当次达标概率模型（对照/核验）

```
logit P(h_ij = 1 | t_ij, B0_i) = η0 + η1·(t−18) + η2·(B0−B̄0) [+ η3·(t−18)²]
```

statsmodels GEE（孕妇聚类、独立工作相关、稳健方差）。p(t|B0) 单调性检查；与 F(t|B0) 在相同网格比较：差距小 → 持续达标假设可接受，风险函数可用 F；差距明显 → 以 p 为风险输入并报告。平方项仅当 AIC/验证改善时保留。

## 5. 潜在风险函数（情景定义，非医学事实）

```
R_g(t) = w_f · [1 − p_g(t)] + w_d · D(t)
D(t) = 0                    t ≤ 12
       (t − 12) / 15        12 < t < 27      （线性升至 27 周达 1）
       1                    t ≥ 27
```

- `1 − p_g(t)`：组 g 在 t 检测的当次未达标比例（标准化损失，代理“结果不可靠”）；
- `D(t)`：延迟发现风险，按题面“≤12 低、13–27 高、≥28 极高”标准化为分段线性，候选域内最高到 25 周对应 13/15≈0.87；
- 基准情景 w_f = w_d = 1；敏感性情景 (w_f, w_d) ∈ {(2,1), (1,1), (1,2)}，并给 D 的保守/激进变体（平台起点 11/13 周）；
- 约束方案对照：在 p_g(t) ≥ 0.95 约束下取最早 t（不满足时取 p 最大时点并标注）。

## 6. BMI 分组优化

- 决策变量：组数 g∈{2,3,4,5}，分界点取自 BMI 排序序列的相邻样本中点；每组孕妇数 ≥30。
- 组内汇总：p_g(t) = mean_i∈g p(t|B0_i)（对个体曲线按组边际化）；F_g 同理。
- 目标（约束型主方案）：每段取组内平均 F≥0.95 的最早时点，不可行段费用为 ∞（严格约束），DP 最小化总人·周；风险最小化 R_g(t) 作为权重情景敏感性。t 网格 11–25 周、步长 0.5。
- 组数选择：报告 g=2..5 的总风险，取“最小 g 使总风险不超过最优值的 102%”（肘部规则），并用 bootstrap 稳定性复核。

## 7. 检测误差影响分析

方差分解：Q1 事件级残差方差 s0² = σ_b²+σ² 已含单次测量误差 ŝ²（绝大多数事件单次测序），潜在（个体+生物）方差 s_L² = s0² − ŝ²；含误差观测方差即 s0²，不再叠加。

- 潜在当次达标概率：p_L(t,x) = 1 − Φ((0.04 − m)/s_L)；观测口径：p_O(t,x) = 1 − Φ((0.04 − m)/s0)；
- 当次误判率：同一潜在浓度 Y* 与观测 Y_obs=Y*+e 的联合正态跨阈值概率（二者相关，不作独立 Bernoulli）；
- 阈值平移敏感性：y_hit 以 0.04±ŝ 重构删失并重走 AFT 主链条，直接报告主方案的分界点与 t\* 变动；
- 分布不确定性：对数正态与 Weibull（AIC 差 0.45 不足以定唯一分布）同链条报告，正式结论采用区间表述。

## 8. 验证设计

1. 锚点 A（MLE 自校准）：按已知 (α0,α1,σ) 仿真区间删失数据，MLE 应恢复参数（相对误差 <10%）；失败先查实现。
2. 锚点 B（方向与单调）：α1>0；p_g(t) 对 t 非降、对 B0 非升（网格上允许蒙特卡洛/拟合抖动 ≤0.005）。
3. 锚点 C（极端情景）：w_d=0 时 t\* 应取 p 最大（候选域末端）；w_f=0 时 t\* 应取最早时点；偏离即实现错误。
4. 校准：BMI 三分组 × 时间分箱，观测达标比例 vs F 预测（事件数加权），报告平均绝对校准误差。
5. 稳定性：200 次按孕妇 bootstrap，报告各组分界点与 t\* 的分布（SD、90% 区间）；权重情景下 t\* 变化表。

## 9. 算法步骤（编程手可执行）

1. 读 Q1 采血级视图，构造删失视图并正式计数（左/区间/右/反转）。
2. 拟合对数正态 AFT（+Weibull 对照），输出参数、区间、AIC；锚点 A/B。
3. 拟合当次 logistic GEE；网格比较 F 与 p̂，决定风险函数输入并记录结论。
4. 定义情景（基准+敏感性+约束对照），DP 求解 g=2..5 的分段与 t\*，肘部规则定 g。
5. Q1 边际模型算 p₀/p₁，重算 t\* 与风险，输出误差影响表。
6. 校准表与图；200 次 bootstrap 稳定性；汇总主表。
7. 更新 Q2 README、P0 状态、Q3 接口说明。

停止条件：模型收敛、锚点通过、主表/敏感性/误差表齐全。

## 10. 结果解释方式

- 分界点与 t\* 是“给定风险情景 + 网格 + 目标函数”下的最优，须连同权重情景一起报告；
- 推荐时点只适用于基线 BMI 已知的人群情景，不是个体精确最优；
- 早于 11 周的推荐是外推，报告中显式标注；
- α1 的单位是 log 周/(kg/m²)：exp(α1) 为 BMI 每 +1 的达标时间中位数倍数。
