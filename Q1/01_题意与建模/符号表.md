# Q1 符号表

| 符号 | 含义 | 单位/范围 | 来源/说明 |
|---|---|---|---|
| `i` | 孕妇编号（孕妇代码） | 无量纲 | B 列，与工作表联合标识个体 |
| `j` | 采血事件序号 | 无量纲 | 孕妇代码 + 抽血次数核验后确定 |
| `Y_ij` | 事件 j 的 Y 染色体浓度（重复均值） | 0–1 比例 | V 列 |
| `t_ij` | 事件 j 的孕周 | 周 | J 列解析，周 + 天/7 |
| `t_c` | 中心化孕周 `t − 18` | 周 | 派生，18 为支持域中部常数 |
| `B_i0` | 基线 BMI（首次事件的本次 BMI） | kg/m² | K 列；决策时可得口径 |
| `B0_c` | 中心化基线 BMI `B_i0 − mean(B0)` | kg/m² | 中心化常数训练折内计算 |
| `ΔB_ij` | BMI 个体内变化量 `B_ij − B_i0` | kg/m² | 派生 |
| `β0…β4` | M0 固定效应系数 | 比例/相应单位 | 待估计 |
| `α_k, B_k(·)` | M1 孕周样条系数与基函数（df=3） | 比例 | 自然三次样条 |
| `γ, Z_ij` | 协变量系数与向量 | 见变量表 | 年龄、IVF、GC、比对、过滤、log 读段 |
| `b_i` | 孕妇随机截距 | 比例 | `N(0, σ_b²)` |
| `ε_ij` | 残差 | 比例 | `N(0, σ²)` |
| `σ_b², σ²` | 随机截距方差、残差方差 | 比例² | 待估计 |
| `ICC` | 组内相关 `σ_b²/(σ_b²+σ²)` | 0–1 | 个体内相关强度 |
| `d` | 同事件技术重复差 `Y_r1 − Y_r2` | 比例 | 技术重复视图 |
| `ŝ` | 单次测量误差估计 `SD(d)/√2` | 比例 | 独立零均值同方差假设下 |
| `n_rep` | 事件内重复检测条数 | 条 | 采血级视图 |
| M0 / M1 | LMM 基线 / 样条混合模型 | — | 模型标识，见模型与算法 |

量纲核对：浓度为 0–1 比例；β1 单位为 比例/周；β2 为 比例/(kg/m²)；交互 β4 为 比例/(周·kg/m²)；所有加法项均为比例尺度，一致。
