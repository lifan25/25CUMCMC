# Q3 模型与算法

## 1. 采用模型与理由

| 组件 | 采用 | 理由 |
|---|---|---|
| 多因素达标时间模型 | 多变量区间删失 AFT（对数正态主选，Weibull 对照） | 与 Q2 同族、可复用同一似然与 DP 优化器；系数即时间比，可解释 |
| 协变量筛选 | 按孕妇 5 折 CV 删失 NLL 改善 + 全数据系数区间不含 0（双条件） | 防止 267 人小样本上过拟合；与 Q1 筛选风格一致 |
| 分组优化 | 组内个体曲线按真实协变量分布边际化 + 同一约束型 DP | 输出仍是可执行的 BMI 分组，个体化信息进入组平均 |
| 误差分析 | 阈值 ±ŝ 平移重走主链条 + 联合正态误判率 | 与 Q2 口径一致，可比 |

不启用树模型/随机斜率：先看多因素 AFT 的 CV 收益；非线性交互无稳定证据时不加复杂度。

## 2. 变量表（逐孕妇基线值）

| 变量 | 定义 | 类型 | 处理 |
|---|---|---|---|
| `B0c` | 基线 BMI − 均值 | 连续 | 主分组变量，必留 |
| `age_c` | 首次事件年龄 − 均值 | 连续 | 候选 |
| `height_c` | 身高 − 均值（cm） | 连续 | 候选（与 BMI 共同表示体型，体重不入主模型） |
| `IVF` | 自然受孕 / IUI / IVF | 类别 | 候选，自然受孕为参照 |
| `parity_preg` | 怀孕次数 1 / 2 / ≥3 | 类别（顶端编码） | 候选，1 为参照 |
| `parity_birth` | 生产次数 0 / 1 / 2+ | 类别 | 候选，0 为参照（2、3 合并防稀疏） |

## 3. 模型公式

```
log T_i = α0 + α1·B0c_i + γ′X_i + σ·ε_i，ε ~ N(0,1)
F(t|B0,X) = Φ((log t − α0 − α1·B0c − γ′X)/σ)
```

区间删失似然同 Q2（左 F(t_R)、区间 F(t_R)−F(t_L)、右 S(t_L)），L-BFGS-B 多初值，数值 Hessian 给 SE。时间比 TR_k = exp(γ_k)：协变量每单位使达标时间中位数乘 TR。

筛选流程：基线 = 仅 B0c（Q2 模型）；候选逐个加入，CV 删失 NLL 改善且区间不含 0 者保留；最终模型 = B0c + 保留项，REML 式重估（重拟合全数据）。

## 4. 组内边际化与分组优化

与 Q2 相同：个体曲线 F(t|B0_i,X_i) 在 t 网格 11–25（步长 0.5）上计算；按 BMI 排序，约束型 DP（组内平均 F≥0.95 最早时点，不可行段费用 ∞，最小组 30 人，g=2..5 肘部规则 0.25 周）。组 g 的达标比例 p_g(t*) = 组内平均 F(t*)。

与 Q2 的公平对照：在同一主表格式下比较分界点、推荐周、p_g(t*)；另报多因素模型的 CV NLL 增益（相对仅 BMI 基线）与 bootstrap 稳定性变化。

## 5. 误差与敏感性

1. 阈值 ±ŝ 平移：重构删失 → 重拟合多因素 AFT → 重优化，报告分界点与 t* 变动。
2. 联合正态误判率：沿用 Q2 方法（Y* 与 Y_obs=Y*+e 的跨阈值概率），按 Q3 推荐时点逐组计算。
3. bootstrap 200 次（按孕妇、检查收敛、整套方案可行率）：分界点与 t* 分布。
4. Weibull 对照同链条（模型不确定性）。

## 6. 验证设计

- 锚点 A：多变量 AFT 仿真恢复（含 2 个协变量），5 数据集均值相对误差 <15%。
- 锚点 B：α1>0 稳定；时间比方向可解释（如年龄增大若 TR>1 则高龄达标更晚）。
- 锚点 C：低 BMI 组 t* ≤ 高 BMI 组 t*（主方案）。
- 锚点 D：恒等核对——协变量全零（均值处）时多因素模型退化为 Q2 模型形式。
- 分组后 BMI 仍是主导：检查各组 t* 差异主要来自 B0c 而非协变量构成偶然性（报告组间协变量均值表）。

## 7. 算法步骤（编程手可执行）

1. 从附件抽取逐孕妇基线协变量（首次事件值），核查恒定性并记录；与 Q2 删失视图合并。
2. 构造设计矩阵（连续中心化、类别哑变量）；拟合 BMI-only 基线与候选模型，输出筛选表（CV NLL、系数区间）。
3. 拟合最终多因素 AFT（对数正态 + Weibull 对照），输出效应主表（系数、SE、CI、p、时间比）。
4. 个体曲线 → 约束型 DP → Q3 组别策略主表；与 Q2 主表并排对照。
5. 误差阈值平移、误判率、bootstrap、Weibull 敏感性。
6. 锚点 A–D 与恒等核对；更新 README、检查记录、论文素材、P0。

停止条件：收敛、锚点通过、主表/敏感性/稳定性齐全。

## 8. 结果解释方式

- γ_k>0（TR>1）：该因素使达标更晚；解释时每单位/每类对照说明。
- 若多因素模型 CV 无稳定增益：如实报告“BMI 之外因素对达标时间的增量信息有限”，Q3 分组退回 Q2 结果并说明——这也是对问题三的有效回答。
- 推荐区间表述沿用 Q2（主解 + 分布/阈值敏感性区间）。
