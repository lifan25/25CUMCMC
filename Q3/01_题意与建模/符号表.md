# Q3 符号表（v3）

| 符号 | 含义 | 单位/范围 | 来源 |
|---|---|---|---|
| `T_i` | 潜在首次达标孕周 | 周 | Q2 删失视图 |
| `X_i` | 预指定协变量（年龄/身高/怀孕/生产） | 见变量表 | 附件基线值 |
| `λ` | 岭惩罚强度 | {0,0.3,1,3,10} | CV 选择 |
| `p_i(t)` | 当次达标概率（GEE 多因素） | 0–1 | 风险输入 |
| `F_i(t)` | 首次跨越累计概率（AFT M1） | 0–1 | 报告用 |
| `U_i(t)` | 测量误差误判率（联合正态） | 0–1 | Q1 方差分解 + ŝ |
| `R_i(t), R_g(t)` | 个体/组内风险 | 标准化损失 | w_f(1−p)+w_d·D+w_e·U |
| `w_f, w_d, w_e` | 未达标/延迟/误差权重 | 情景参数 | 基准 20:1:1 |
| `t*_g, t*_i` | 组基础时点 / 个体最优时点 | 周 | DP / argmin |
| `Δ_i` | 个体修正量 | {0, 0.5, 1.0} 周 | clip(round((t*_i−t*_g)/0.5)×0.5, 0, 1) |

量纲核对：R 三项均为概率尺度标准化损失；γ′X 为 log 周；其余同 Q2。
