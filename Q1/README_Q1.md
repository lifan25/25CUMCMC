# Q1：Y 浓度关系与显著性

## 最终回答

Y 染色体浓度随孕周显著上升、随基线 BMI 显著下降：在 1021 个采血事件（267 名孕妇）上，孕周每增加 1 周，浓度平均升高 0.00288（约 0.29 个百分点，95%CI 0.00251–0.00326，p≈5e-52）；基线 BMI 每增加 1 kg/m²，浓度平均降低 0.00220（约 0.22 个百分点，CI -0.00340–-0.00099，p=3.4e-4）。孕期 BMI 变化量（ΔB）与孕周×BMI 交互均不显著（p=0.60、0.12）。孕周的非线性分量统计显著（LRT p≈1e-5）但无预测收益，按预设保留规则采用线性混合模型 M0。

## 主模型

LMM（采用，标识 M0）：`Y = β0 + β1·t_c + β2·B0_c + β3·ΔB + β4·(t_c×B0_c) + γ·log10(唯一比对读段数) + b_i + ε`，孕妇随机截距，REML 估计。
- σ_b²=7.93e-4，σ²=2.94e-4，ICC=0.730（个体差异大，随机截距必要）；边际 R²=0.143，条件 R²=0.768。
- 协变量筛选仅保留 log10(唯一比对读段数)（γ=-0.0206，p=0.0054，测序深度相关质量效应；不作生物解释）。
- 对照：M1 样条混合模型（df=3）按孕妇 5 折验证 wRMSE 改善仅 0.07%（<2% 阈值），不保留；logit 尺度对照无收益（wRMSE 0.03349 vs 0.03304）。

## 输入与数据处理

- 输入：官方附件“男胎检测数据”（只读，1082 行 × 31 列）。
- 清洗（落实 P0 规则）：孕周解析 0 失败（兼容大写 W）；BMI 无缺失；无完全重复行。
- 事件核验：1082 行 → 1021 个采血事件；40 个多记录事件（101 行）全部核验为同次采血——抽血次数、孕周、年龄、身高、体重一致，仅检测日期差 0–6 天（测序日期）；1 个事件（A055|3）孕周字段冲突（21w+1 与 20w+3），取均值并标记 `week_conflict`。
- 基线 BMI = 按孕周排序首次事件的本次 BMI；ΔB = 本次 − 基线。

## 主要验证

- 锚点 1：σ_b²=0 人工数据上 MixedLM 退化为 OLS（|Δβ|<1e-3），通过。
- 锚点 2：β1>0、β2<0 方向先验成立。
- 锚点 3：11–25 周边际均值预测 0.061–0.101，在经验范围内。
- 按孕妇 5 折交叉验证（种子 42）：M0 孕妇等权 wMAE=0.0271、wRMSE=0.0330；与 M1、logit 对照见验证主表。
- 残差 QQ 与残差-拟合值图：近似正态、低ess 近零；轻度右偏（偏度 0.58），logit 尺度对照确认不影响选模。

## 技术重复误差（供 Q2/Q3）

82 对同次采血重复差：SD=0.0083，单次测量误差估计 ŝ=SD/√2=0.0058（0.58 个百分点），为 4% 阈值的 14.6%。阈值附近判断可能被误差翻转，Q2 误差分析必须使用。

## 限制

- 条件关联非因果；人群以高 BMI 为主，孕周支持域 11–29 周，低 BMI 与 11 周前不外推。
- 217/267 名孕妇首次事件即达标，早期段关系识别较弱。
- 边际 R²=0.143：孕周/BMI 只解释少部分变异，个体差异（ICC=0.73）占主导。
