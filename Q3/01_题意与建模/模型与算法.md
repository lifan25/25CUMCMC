# Q3 模型与算法（v5）

## 1. 模型分工

| 组件 | 模型 | 作用 |
|---|---|---|
| M0 | BMI-only 区间删失对数正态 AFT＋BMI-only 岭 Logistic | Q2式基线 |
| M1-AFT | 年龄、身高、孕产史预指定进入岭 AFT | 估计潜在首次跨越概率 `F_i(t)` |
| M1-current | 孕周、BMI、年龄、身高、孕产史进入按孕妇等权的岭 Logistic | 估计当次达标概率 `p_i(t)` |
| 误差层 | Q1事件级方差与单次测量误差的联合正态跨阈值概率 | 得到误判概率 `U_i(t)` |
| 决策层 | 归一化理想点折中＋BMI有序动态规划＋年龄/身高约束树 | 给出BMI一级边界、年龄身高二级区间及组时点 |

IUI、IVF各2人，不足以可靠估计，只保留描述。体型用 BMI+身高为主表达，体重+身高作为重参数化对照；最终分组轴按题面使用基线 BMI。

## 2. 联合模型

潜在首次跨越时间满足

`log T_i = α0 + α1 B0c_i + γ'X_i + σε_i`，

其中 `X_i` 包含年龄、身高、怀孕次数和生产次数，`γ` 采用岭惩罚。标准化和参数估计只在相应训练折内完成，5折验证按孕妇划分。

当次模型为

`logit p_ij = θ0 + θt(t_ij-18) + θB B0c_i + θ'X_i`。

每名孕妇的事件权重和为1，避免检测次数较多者主导拟合；全部非截距系数使用岭惩罚，解决生产2次及以上类别的完全分离。惩罚参数通过按孕妇5折 CV Brier 选择。

## 3. 误差传播与折中目标

设潜在浓度 `Y*~N(m_i(t),s_L²)`，单次误差 `e~N(0,ŝ²)`，则

`U_i(t)=P[(Y*-0.04)(Y*+e-0.04)<0]`。

可靠性损失取 `A_g(t)=mean[1-p_i(t)+U_i(t)]`，延迟损失为

`D(t)=clip((t-12)/15,0,1)`。

由于二者量纲和变化范围不同，先在11–25周候选域内分别归一化，再计算到理想点 `(0,0)` 的距离：

`S_g(t)=sqrt((w_r A'_g(t))²+(w_d D'(t))²)/sqrt(w_r²+w_d²)`。

主情景取 `w_r:w_d=1:1`；0.5:1和2:1分别表示偏早与偏稳。该权重只表达相对偏好，故同时报告情景范围，不把它解释为临床成本。

## 4. BMI一级分组、年龄身高二级区间和个体层

按基线 BMI 排序，对连续区间计算 `n_g min_t S_g(t)`，用动态规划求1–5段中的最优分段；题目明确要求分组，因此可行解至少2组。为保证每个主组还能分成4个样本量不少于12的二级叶节点，一级组最少48人。若增加一组的总得分相对改善不足1%，停止细分。

在每个冻结的BMI主组内，分别枚举两种二层结构：`年龄→身高`和`身高→年龄`。第一层选一个连续切点，第二层在其左右分支分别选另一个变量的切点，共形成4个覆盖且互斥的矩形叶节点。所有切点只用当前建模样本，以四叶总风险得分最小为准，每叶至少12人；最终两组均选出`年龄→身高`。这是真实优化得到的区间，不把中位数或四分位数冒充最优阈值。

嵌套分组与一级方案使用相同的概率模型、误差项、候选时点和目标函数，因此总得分变化可归因于增加年龄/身高区间。样本内相对改善仅0.06%，八个子组的时点仍为所属BMI主组的17.5或18.0周；二级区间主要用于区分当次可靠性和复检强度。

个体层使用同一折中得分计算 `t_i*`，只允许相对组基础时点保守后移0、0.5或1周。当调整后 `p_i<0.8`，或建议时点抵达25周边界时，标记“建议复检”。个体建议不替代组统一方案。

## 5. 验证

- 锚点：AFT仿真恢复；BMI方向为正；低BMI组时点不晚于高BMI组；仅延迟时取最早点。
- M0/M1按孕妇5折比较删失NLL和Brier。
- 误差取0、ŝ、2ŝ，每次重新计算 `U`、分组和时点。
- 100次按孕妇cluster bootstrap：重复抽中的孕妇复制全部事件并赋新聚类编号，重新拟合当次模型和优化；一级方案100次完成，完整四叶嵌套85次可行。分别报告一级分界/时点、嵌套顺序和同单位切点区间，不把求解成功等同于真实世界成功率。
- Weibull只作为首次跨越 `F` 的分布对照，不冒称会改变以当次 `p` 为核心的决策。
