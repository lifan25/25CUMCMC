# Q3 模型与算法（v3）

## 1. 模型体系

| 组件 | 采用 | 角色 |
|---|---|---|
| M0：BMI-only 区间删失 AFT | 同 Q2（对数正态） | 基准对照 |
| M1：多因素岭正则化 AFT | log T = α0 + α1·B0c + γ′X + σε，γ 岭惩罚 λΣγ²，λ 由 CV 选 | Q3 主模型（潜在首次跨越时间） |
| 体型参数化 | A：BMI+身高 vs B：体重+身高，CV 删失 NLL 选择 | 处理 Weight=BMI×Height² 确定性共线 |
| 当次达标模型 | 多因素 GEE：logit p = θ0 + θ_t·(t−18) + θ_B·B0c + θ′X，孕妇聚类 | 当次达标比例（风险函数输入） |
| 误差不确定性 | U_i(t) = 联合正态误判率（Y* 与 Y*+e 跨阈值概率，Q1 方差分解） | 风险第三项 |
| 优化 | R_i(t) = w_f(1−p_i) + w_d·D(t) + w_e·U_i(t)，组内平均，DP 有序分段 | 分组与时点 |
| 个体层 | Δ_i = clip(round((t*_i − t*_g)/0.5)×0.5, 0, 1) | 两层输出的第二层 |

协变量 X（预指定，不筛选）：年龄、身高、怀孕次数（2/≥3 哑变量）、生产次数（1/2+ 哑变量），标准化后入岭；IUI/IVF 各 2 人仅描述。

## 2. 关键公式

- AFT 同 Q2 似然 + 惩罚项；λ ∈ {0, 0.3, 1, 3, 10} 按 5 折 CV 删失 NLL 选。
- D(t) = clip((t−12)/15, 0, 1)（题面三阶段标准化，同 Q2）。
- 组内风险 R_g(t) = mean_i∈g R_i(t)；t*_g = argmin；DP 段费用 n_seg·min R̄，最小组 30 人。
- 组数：严格肘部（再细分相对改善 <1% 停止，防切条）。

## 3. 权重情景

偏早 (5,1,1)、基准 (20,1,1)、偏稳 (40,1,1)、单位权重 (1,1,1)（退化诊断）、极端锚点（仅延迟 (0,1,0) → 11 周、仅可靠 (1,0,0) → 25 周，作实现正确性断言）。

## 4. 验证设计

- 锚点 A：岭 AFT 仿真恢复（真值取可识别量级 ±0.05/SD；区间删失+共线设计下允许衰减，<25% 或绝对 <0.015）。
- 锚点 B：α1>0。锚点 C：低组 t* ≤ 高组 t*。锚点 D：λ=0 且仅 B0c 复现 Q2 冻结参数（<2e-3）。锚点 E：极端权重边界解。
- 决策增益表：AFT CV NLL、当次 CV Brier、分界/时点变化、调整人数、高风险尾部（当次 p<0.8 人数）、M0 对照方案。
- bootstrap 100 次（M1+GEE+风险全链条，检查收敛）：分界点/t* 分布 + 冻结方案风险 90% 区间。
- Weibull 与阈值 ±ŝ 全链条敏感性。

## 5. 算法步骤

1. 协变量基线抽取与恒定性记录；标准化参数固定。
2. 锚点 A/D；体型 A/B 选择；λ CV 选择；拟合 M1（两分布）。
3. 多因素 GEE 拟合 + CV Brier（对照 BMI-only GEE）。
4. 误判率查表法构建 U_i(t)（m 网格 701 点 × 联合正态积分）。
5. 风险网格 → 情景 DP → 基准主方案；锚点 B/C/E。
6. 个体最优 t*_i → Δ_i 三档 → 修正表与分层计数。
7. 决策增益表（含 M0 对照方案）；敏感性；bootstrap。
8. 更新 README、检查记录、论文素材、P0。

## 6. 结果解释

- 岭系数以原单位时间比报告（TR>1 达标更晚），不作显著性声明（岭估计区间由 bootstrap 给）。
- 推荐 = 基准情景点估计 + 权重敏感区间 + bootstrap 区间；高组 t* 抵窗口末端时解释为"单检不足，需复检"。
- 个体修正只向保守方向（Δ≥0）：普通风险用基础时点，较高 +0.5 周，极高/不确定 +1 周并建议复检。
