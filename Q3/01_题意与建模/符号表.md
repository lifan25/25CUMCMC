# Q3 符号表（v5）

| 符号 | 含义 | 单位/范围 |
|---|---|---|
| `T_i` | 潜在首次达标孕周 | 周 |
| `X_i` | 年龄、身高、怀孕次数、生产次数等基线协变量 | 各变量原单位 |
| `B0_i` | 基线 BMI | kg/m² |
| `λ_A, λ_p` | AFT和当次Logistic的岭惩罚强度 | 由按孕妇CV选择 |
| `F_i(t)` | 截至t周的潜在首次跨越概率 | 0–1 |
| `p_i(t)` | t周一次检测达到4%的概率 | 0–1 |
| `ŝ` | 单次测量误差标准差 | 浓度小数尺度 |
| `U_i(t)` | 观测值与潜在值跨4%阈值的概率 | 0–1 |
| `D(t)` | 归一化延迟损失 | 0–1 |
| `A_g(t)` | 组可靠性损失 `mean(1-p+U)` | 概率尺度 |
| `S_g(t)` | 可靠性与延迟到理想点的归一化折中得分 | 0–1附近，无量纲 |
| `w_r,w_d` | 可靠性、延迟的相对偏好 | 主情景1:1 |
| `t_g*,t_i*` | 组基础时点、个体折中时点 | 周 |
| `Δ_i` | 个体相对组时点的保守后移量 | 0、0.5或1周 |
| `c_{a,g}` | BMI主组g内的年龄一级切点 | 岁 |
| `c_{h,g}^{(-)},c_{h,g}^{(+)}` | 年龄低/高分支内的身高切点 | cm |
| `L_{gk}` | BMI主组g内第k个年龄—身高叶节点 | 每叶至少12人 |

`F`、`p`、`U`和`S`含义不同，不得相互替代。`S`是标准化代理得分，不是疾病概率或临床费用。
