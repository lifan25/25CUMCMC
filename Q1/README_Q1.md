# Q1：Y 浓度关系与显著性

## 最终回答

Y 染色体浓度随孕周显著上升、随基线 BMI 显著下降：在 1021 个采血事件（267 名孕妇）上，孕周每增加 1 周，浓度平均升高 0.00288（约 0.29 个百分点；Wald 95%CI 0.00251–0.00326，按孕妇 cluster bootstrap CI 0.00227–0.00337，p≈5e-52）；基线 BMI 每增加 1 kg/m²，浓度平均降低 0.00220（约 0.22 个百分点；Wald CI -0.00340–-0.00099，bootstrap CI -0.00352–-0.00102，p=3.4e-4）。孕期 BMI 变化量（ΔB）与孕周×BMI 交互均不显著（p=0.60、0.12）。稳健区间与 Wald 区间一致，显著性结论在残差重尾/异方差下保持。孕周的非线性分量统计显著（LRT p≈1.1e-5）但无预测收益，按预设保留规则采用线性混合模型 M0。

## 主模型

LMM（采用，标识 M0）：`Y = β0 + β1·t_c + β2·B0_c + β3·ΔB + β4·(t_c×B0_c) + γ·log10(唯一比对读段数) + b_i + ε`，孕妇随机截距，REML 估计。
- σ_b²=7.93e-4，σ²=2.94e-4，ICC=0.730（个体差异大，随机截距必要）；边际 R²=0.143，条件 R²=0.768。
- 协变量筛选仅保留 log10(唯一比对读段数)（γ=-0.0206，p=0.0054；bootstrap CI -0.0348–-0.0078。测序深度相关质量效应，不作生物解释）。
- 对照：M1 自然样条混合模型（孕周 df=3 自然样条，固定自由度、无显式平滑惩罚）按孕妇 5 折验证 wRMSE 改善仅 0.07%（<2% 阈值），不保留；logit 尺度对照（含随机效应 Gauss-Hermite 积分的边际口径）wRMSE 0.03338 不优于 0.03304，无收益。
- 显著性核验：500 次按孕妇 cluster bootstrap（0 次拟合失败），孕周与基线 BMI 稳健区间均不含 0。

## 输入与数据处理

- 输入：官方附件“男胎检测数据”（只读，1082 行 × 31 列），路径经 `--xlsx` 参数指定，默认取仓库上级目录 `附件.xlsx`。
- 清洗（落实 P0 规则）：孕周解析 0 失败（兼容大写 W）；BMI 无缺失；无完全重复行。
- 事件核验：1082 行 → 1021 个采血事件；40 个多记录事件（101 行）全部核验为同次采血——抽血次数、孕周、年龄、身高、体重一致，仅检测日期差 0–6 天（测序日期）。
- 孕周冲突：A055|3 两条记录为 21w+1 与 20w+3，按末次月经+检测日期推算为 21.29 周（21w+2），采用核对值并打 `week_conflict` 标记。
- 基线 BMI = 按孕周排序首次事件的本次 BMI；ΔB = 本次 − 基线。

## 主要验证

- 锚点 1：σ_b²=0 人工数据上 MixedLM 退化为 OLS（|Δβ|<1e-3），通过。
- 锚点 2：β1>0、β2<0 方向先验成立。
- 锚点 3：11–25 周边际均值预测 0.061–0.101，在经验范围内。
- 按孕妇 5 折交叉验证（种子 42）：M0 孕妇等权 wMAE=0.0271、wRMSE=0.0330；与 M1、logit 对照见验证主表。
- 残差 QQ 与残差-拟合值图：轻度右偏（偏度 0.58）、超额峰度约 3.4；已用 cluster bootstrap 稳健区间与 logit 尺度对照双重核验，结论保持。

## 技术重复误差（供 Q2/Q3）

101 条重复测序记录（40 个事件）的事件内合并方差：单次测量误差 **ŝ=√(SSW/61)=0.0061**（0.61 个百分点），为 4% 阈值的 **15.3%**。阈值附近判断可能被误差翻转，Q2 误差分析必须使用。

## 限制

- 条件关联非因果；人群以高 BMI 为主，孕周支持域 11–29 周，低 BMI 与 11 周前不外推。
- 217/267 名孕妇首次事件即达标，早期段关系识别较弱。
- 边际 R²=0.143：孕周/BMI 只解释少部分变异，个体差异（ICC=0.73）占主导。
- M1 为固定自由度自然样条混合模型，未做 mgcv 式惩罚估计；其“非线性显著”指样条相对线性的 LRT，不作 GAMM 结论表述。
