# Q4 题意说明

## 官方问题四原文

> 问题 4 由于孕妇和女胎都不携带 Y 染色体，重要的是如何判定女胎是否异常。试以女胎孕妇的 21 号、18 号和 13 号染色体非整倍体（AB 列）为判定结果，综合考虑 X 染色体及上述染色体的 Z 值、GC 含量、读段数及相关比例、BMI 等因素，给出女胎异常的判定方法。

## 题意覆盖映射（按新版 skill《题意覆盖与模型递进》）

| 题目要求 | 数学任务与组件 | 本问最终输出 |
|---|---|---|
| 以 AB 列为判定结果 | 多标签分类：T13/T18/T21 三个独立二元标签；AB 空白=无异常（不当作缺失填补）；多标签组合（T13T18 等）由分染色体预测合成 | 分染色体判定规则与性能主表 |
| 综合考虑 Z 值、GC、读段数及比例、BMI 等因素 | 因素角色预标记（见下）；联合模型（分染色体正则化逻辑回归），不以单特征规则代替联合考虑 | 各因素系数/贡献与证据 |
| 给出判定方法 | 可执行规则：特征 → 概率 → 阈值 → 判定；规则基线（Z 阈值）作对照；阈值按漏检代价情景在训练折内选择 | 可复现的判定流程 + 阈值情景表 |
| （递进要求）相对前三问的增量 | 从连续时点决策到多标签分类；新增规则基线对照与按孕妇分组防泄漏验证 | 规则 vs 模型对照表、训练外性能及区间 |

## 数据核实（只读初查，605 条 / 147 人）

- AB 分布：空白 538；T18 46、T13 23、T21 13（含组合 T13T18 11、T18T21 2、T13T21 2）；有过阳性的孕妇 44 人。
- **8 名孕妇标签随记录变化**（如 B004 先后标 T21、T13）：标签是逐记录的检测结论，存在噪声；按孕妇分组验证防泄漏，并补孕妇级指标。
- 关键字段无缺失（BMI 缺 1 条按身高体重回算）；女胎 Y 染色体 Z 值/浓度结构性空白，不作输入；AE 列恒为"是"，不作目标也不作输入。
- **核心事实：教科书式 |Z|>3 规则在本附件上失效**——T13 召回 0.04/精确 0.05，T18 0/0，T21 0/0；阳性记录的对应染色体 Z 均值并不高于阴性（T13：0.10 vs 0.45）。AB 标签来源未知，本题性能只能解释为"复现 AB 列的能力"，不能等同临床诊断准确性（P0 预警的正式确认）。
- 全特征联合信号初查（分组 CV 逻辑回归）：T13 AUC≈0.79、T18 AUC≈0.82、T21 AUC≈0.57——联合因素有增量，这正是"综合考虑"的用武之地。

## 因素角色

| 因素 | 角色 | 说明 |
|---|---|---|
| 13/18/21 号 Z 值 | 解释（题定主要信号） | 但单阈值失效，需联合 |
| X 染色体 Z 值、X 浓度 | 解释 | 题面点名 |
| GC 含量（总+分染色体）、读段数、比对/重复/过滤比例 | 解释（测序质量） | 检测时可得 |
| BMI、年龄、身高、检测孕周 | 解释 | 题面点名及可得协变量 |
| Y 染色体 Z 值/浓度 | 排除 | 女胎结构性空白 |
| AB 派生字段、AE | 排除（泄漏/无效） | AE 恒为"是" |

## 输出

分染色体判定规则（系数 + 阈值情景）、规则基线对照、记录级与孕妇级性能主表（召回/精确/特异度/F1/PR-AUC 及 bootstrap 区间）、混淆计数、论文素材。

## 约束与边界

1. 训练/验证严格按孕妇代码分组（GroupKFold），同一孕妇记录不跨集合；预处理只在训练折内。
2. 阳性稀少（13–46/605）：正则化 + 类别权重 + bootstrap 区间，不堆叠复杂模型；浅层树仅在非线性且分组验证有收益时对照。
3. 漏检代价高于误报作为建模情景（非题定数值），给基准与敏感性阈值。
4. 性能解释为复现 AB 的能力；若某染色体无稳定训练外信号，如实报告并给出依赖该事实的判定建议。
