# Q2 符号表

| 符号 | 含义 | 单位/范围 | 来源/说明 |
|---|---|---|---|
| `T_i` | 孕妇 i 潜在首次达标孕周 | 周 | 不可直接观测，删失 |
| `t_ij, h_ij` | 事件孕周与当次达标标记 | 周；0/1 | Q1 采血级视图 |
| `B0_i` | 基线 BMI（首次事件） | kg/m² | Q1 视图 |
| `F(t\|B0)` | 首次达标累计概率 | 0–1 | AFT 主模型 |
| `p(t\|B0)` | 当次检测达标概率 | 0–1 | GEE 对照 / Q1 边际模型 |
| `α0, α1, σ` | AFT 截距、BMI 系数、尺度 | log周、log周/(kg/m²)、log周 | 待估计 |
| `η0..η3` | 当次 logistic 系数 | logit | GEE |
| `R_g(t)` | 组 g 在 t 检测的综合风险 | 标准化损失 | 情景定义 |
| `D(t)` | 延迟发现风险函数 | 0–1 | 分段线性，题面三阶段标准化 |
| `w_f, w_d` | 未达标与延迟权重 | 情景参数 | 基准 1,1；敏感性 (2,1),(1,2) |
| `p_g(t)` | 组 g 在 t 的组内平均当次达标概率 | 0–1 | 个体曲线组内边际化 |
| `ŝ` | 单次测序误差 | 0.0061 比例 | Q1 事件内合并方差 |
| `s0²` | Q1 边际浓度方差 σ_b²+σ² | 比例² | Q1 效应主表 |
| `g, t*` | 组数、组内最佳时点 | 个；周 | 优化结果 |
| `p₀, p₁` | 无/有测量误差的当次达标概率 | 0–1 | 误差传播 |

量纲核对：log T 为 log 周；α1·B0 为 log 周；R 中两项均为 0–1 标准化损失，权重无量纲；p、F 为概率。
