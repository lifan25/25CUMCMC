# Q1 模型与算法

## 1. 采用模型与理由

| 模型 | 角色 | 理由 |
|---|---|---|
| M0：线性混合效应模型（LMM，孕妇随机截距） | 基线 | 直接回答孕周、BMI 的线性条件关联，可解释、可检验；随机截距处理个体内相关，避免重复记录虚增样本量 |
| M1：低复杂度样条混合模型（GAMM 的低复杂度形式） | 首选候选主模型 | 孕周–浓度关系在文献与常识上可能非线性（快速增长后趋缓）；用低自由度自然三次样条代替线性孕周项，其余结构同 M0，自由度低即等效强惩罚，防止过拟合 |

环境约束：本机无 R/mgcv，采用 Python statsmodels MixedLM 实现。自然样条基以固定自由度（df=3）进入设计矩阵，这是“受惩罚低复杂度平滑”的实用等价形式；不额外引入依赖。

保留规则（与 Q1 启动接口一致）：先要求收敛、随机结构可识别、预测范围合理；M1 仅在按孕妇验证误差稳定改善（各折方向一致且孕妇等权 RMSE 改善 >2%）且曲线呈明确非线性时保留，否则采用 M0。差异小且无明确非线性证据时选 LMM。

备选仅在明确缺口时启用：残差明显偏态/异方差 → logit(Y) 尺度对照（回变换用 smearing 估计群体期望）；比例分布仍不匹配 → Beta 混合回归；群体平均推断需稳健化 → GEE（交换相关）。本轮不预设训练备选。

## 2. 数据准备算法（落实 P0 数据规则）

1. 读取“男胎检测数据”，保留原始行号；列名去首尾空格。
2. 孕周解析：兼容 `w/W`，`周 + 天/7` 转为小数周，保留原值；无法解析则标记。
3. BMI 缺失由同次有效身高/体重回算并标记（男胎表本轮复核未见 BMI 缺失，规则仍执行）。
4. 事件核验：候选键 = 孕妇代码 + 检测抽血次数；交叉核对检测日期、孕周、年龄、身高一致性；一致才认定同次采血事件。完全重复行先核验，不按键批量删除。
5. 采血级视图：同事件 Y 浓度取算术均值，保留重复数 `n_rep` 与重复极差；本次 BMI、孕周取事件内一致值（不一致则标记并取首值）。跨次采血全部保留。
6. 派生变量：`B0` = 该孕妇按孕周排序首次事件的本次 BMI（基线口径）；`ΔB` = 本次 BMI − B0；中心化 `t_c = t − 18`、`B0_c = B0 − mean(B0)`（中心化常数在训练折内计算）。
7. 技术重复视图：同事件内 Y 的两两差；事件内仅 2 条时直接给出差值，多于 2 条时给出全部两两差及极差。

## 3. 变量表

| 角色 | 符号/变量 | 单位/范围 | 来源 |
|---|---|---|---|
| 响应 | `Y_ij` | 0–1 比例（原始尺度） | V 列事件均值 |
| 核心解释变量 | `t_c = t_ij − 18` | 周 | J 列解析 |
| 核心解释变量 | `B0_c = B_i0 − mean(B0)` | kg/m² | K 列（首次事件） |
| 核心解释变量 | `ΔB_ij = B_ij − B_i0` | kg/m² | K 列 |
| 交互 | `t_c × B0_c` | 周·kg/m² | 派生 |
| 候选协变量 | 年龄、IVF 妊娠（自然/IUI/IVF）、GC 含量、比对比例、过滤比例、log10(唯一比对读段数) | 见数据字典 | C/G/P/M/AA/O 列 |
| 随机效应 | `b_i` 孕妇随机截距 | 比例尺度 | 派生 |

协变量纳入规则：先拟合仅含核心变量的模型；候选协变量逐个加入，仅当按孕妇验证误差改善且系数区间不含 0 时保留；不以训练折内 p 值做纯粹筛选。质量变量（GC、读段）用于控制测序质量对浓度的影响，不解释为生物效应。

## 4. 模型公式

M0（LMM 基线）：

```
Y_ij = β0 + β1·t_c,ij + β2·B0_c,i + β3·ΔB_ij + β4·(t_c,ij × B0_c,i) + γ′Z_ij + b_i + ε_ij
b_i ~ N(0, σ_b²)，ε_ij ~ N(0, σ²)，b_i 与 ε_ij 独立
```

M1（样条混合模型）：将 `β1·t_c + β4·(t_c×B0_c)` 替换为自然三次样条展开

```
f(t_ij; df=3) = Σ_k α_k·B_k(t_ij)，并可含样条基 × B0_c 线性交互
```

其余项同 M0。M0 是 M1 的特例（样条退化为线性时），二者可在同一数据口径下嵌套比较。

假设（需检验/讨论）：给定固定效应后误差独立同方差；`b_i` 正态且与解释变量独立；采血级均值汇总在重复差异小时不扭曲浓度水平（用中位数汇总作对照）；关联为条件关联非因果。

## 5. 估计与显著性

- 估计：statsmodels MixedLM；固定效应结构比较用一致 ML 口径，最终报告 REML 估计。
- 显著性：核心系数给 Wald 统计量与 95% 区间；交互项无论显著与否都按预设报告，不以 p 值删项后重报。
- M1 孕周整体效应与非线性分量：ML 拟合嵌套模型的似然比检验（样条 vs 线性 vs 无孕周项），报告效应曲线与逐点置信带。
- 随机效应：报告 σ_b²、σ² 与 ICC = σ_b²/(σ_b²+σ²)；方差边界问题不以常规卡方检验机械判定。
- 解释度：报告边际 R²（固定效应）与条件 R²（含随机效应）。

## 6. 选模验证（按孕妇分组）

1. 按孕妇代码分 5 折（固定随机种子），同一孕妇全部记录只属一折。
2. 中心化常数、基线 BMI、任何变换参数仅用训练折估计。
3. 对验证折孕妇做边际预测（b_i = 0，原始尺度）；逐孕妇先平均绝对误差再按孕妇等权汇总，报告 MAE、RMSE。
4. 诊断：残差 QQ 图、残差–拟合值图（异方差）、按孕周/BMI 分箱残差、影响点（高杠杆孕妇）。
5. 执行保留规则，记录结论与证据。

## 7. 技术重复误差估计（供 Q2/Q3）

事件内两条重复之差 `d = Y_r1 − Y_r2`；在独立、零均值、同方差假设下，单次测量误差 `ŝ = SD(d)/√2`。报告 `d` 的分布、`ŝ`、及其相对 4% 阈值的幅度（`ŝ` 与 0.04 的比值），并标注假设与局限（同次重复不能识别共同系统偏差）。该结果只作误差线索，不替代 Q2 的正式误差传播。

## 8. 算法步骤（编程手可执行）

1. 按第 2 节生成采血级视图与技术重复视图，输出 CSV 与纳入/排除及标记统计（记录数、人数、事件数、重复事件数）。
2. 探索：Y–孕周、Y–BMI 散点与分箱均值、个体轨迹样本、B0 与 ΔB 相关结构；输出支持域统计（孕周、BMI 范围、分箱样本量）。
3. 拟合 M0（ML + REML），提取系数、区间、σ_b²、σ²、ICC、边际/条件 R²。
4. 拟合 M1（样条 df=3，ML + REML），做嵌套 LRT（非线性分量），生成孕周效应曲线（固定 B0_c=0、ΔB=0）。
5. 候选协变量按第 3 节规则筛选，形成最终固定效应结构（ML 比较，REML 复估）。
6. 5 折按孕妇验证 M0 与 M1（相同折、相同预测任务），输出验证主表。
7. 残差与影响诊断；触发条件满足时拟合 logit 尺度对照并比较原始尺度回变换误差。
8. 汇总：模型效应主表 `q1_effects_main.csv`、验证主表 `q1_validation.csv`、采血级视图 `q1_blood_events.csv`、技术重复视图 `q1_technical_replicates.csv`；生成效应曲线图与诊断图。
9. 更新 Q1 README、P0 模型状态与接口。

停止条件：模型收敛（优化器正常退出）且验证主表、效应主表、诊断图齐全；备选模型仅在触发条件满足时增加。

## 9. 锚点（实现正确性与方向检查）

- 锚点 1（恒等退化）：在 σ_b² = 0 的人工数据上，MixedLM 估计应退化为同设计矩阵 OLS；实现时断言 `|β_MixedLM − β_OLS| < 1e-6`。若断言失败，先查实现再谈结果。
- 锚点 2（方向先验）：基于题面“紧密相关”与 NIPT 常识，预期 `β1 > 0`（浓度随孕周上升）且 `β2 < 0`（高基线 BMI 对应更低浓度）；若符号相反，必须检查数据口径而非直接采信。
- 锚点 3（范围检查）：在 t∈[11,25] 周、B0∈[25,40] 的网格上，拟合边际均值应落在 (0, 0.15) 的经验范围内；越界即为外推异常信号，须报告而非隐藏。

## 10. 结果解释方式

- `β2`：基线 BMI 每增加 1 kg/m²，同一孕周与变化量下 Y 浓度的条件平均差（比例单位）。
- `β1`（或 M1 曲线）：BMI 结构不变时浓度随孕周的平均变化。
- 显著性回答“总体作用是否可分辨”，效应区间回答“多大”；二者同时报告。
- 结论只适用于支持域内、以高 BMI 为主的人群；不声称因果，不外推到 11 周前或低 BMI。
